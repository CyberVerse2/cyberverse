## Learned User Preferences

- Keep site copy short and jargon-free; use the user's wording for project and article blurbs instead of expanding them into marketing.
- Prefer high-contrast, readable type (body around 400, titles around 500) on near-white paper; do not use thin 300 weights or heavily muted colors for reading copy.
- Keep layout spacing tight; the user notices excess whitespace between sections and list items.
- Project listings should be name plus short description only—no logos and no years.
- UI labels should stay quiet and typographic; avoid uppercase accent-colored badges.
